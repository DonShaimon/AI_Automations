# ASPICE PLATPD Report Template

Copy this structure for every generated report; replace bracketed placeholders.

> **Optional HTML output:** after saving the `.md` report, an HTML version with every work-item ID auto-linked to
> its Polarion page can be generated by running
> [../references/md-to-html.ps1](./md-to-html.ps1) `-InputPath "reports/<PLATPD-ID>-ASPICE-report.md"`
> — see SKILL.md step 8. Always regenerate the HTML from the finalized markdown; don't hand-edit it separately.
